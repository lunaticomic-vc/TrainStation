## Клас `TicketManager`

`TicketManager` не е клас сам по себе си, а по-скоро модул с функции за закупуване на билети, използвани от потребителите (включително с карти за намаление).

---

### Основни функции

#### `void buyTicket(Train& train, int wagonID, int seatID, const std::string& fileName, const std::vector<std::string>& extraParams)`

**Описание:** Закупува билет без намаление.

**Параметри:**

* `train` — препратка към влака.
* `wagonID` — ID на вагона, в който се купува мястото.
* `seatID` — ID на мястото (започва от 1).
* `fileName` — файлът, в който се запазва билетът.
* `extraParams` — допълнителни параметри (например за багаж).

**Логика:**

1. Проверява дали вагонът съществува и дали мястото е свободно.
2. Изчислява цената според параметрите и типа на вагона.
3. Заделя мястото и създава билет във файл.

---

#### `void buyTicketWithDiscount(Train& train, int wagonID, int seatID, const std::string& fileName, const std::string& cardFile, const std::vector<std::string>& extraParams)`

**Описание:** Закупува билет с използване на карта за намаление.

**Параметри:**

* `train`, `wagonID`, `seatID`, `fileName`, `extraParams` — същите като при `buyTicket`.
* `cardFile` — файл с данни за картата.

**Логика:**

1. Отваря и парсва файла с карта (първите 4 реда).
2. Проверява дали картата е валидна чрез `isCardValid`.
3. Определя какъв вид карта е:

   * `AgeCard`: Прилага се намаление според възрастта.
   * `RouteCard`: 100% намаление, ако дестинацията съвпада.
   * `DistanceCard`: Намаление, ако разстоянието е в допустимите граници.
4. Изчислява финалната цена.
5. Заделя мястото и създава билет с намалението във файл.

---

### Поддържащи структури и функции

#### `std::unordered_set<std::string> validCardIDs`

Множество с всички валидирани ID на карти.

#### `bool isCardValid(const std::string& cardID)`

Проверява дали дадено ID е включено във `validCardIDs`.

---

### Особености

* Използва `calculatePrice()` от вагона за изчисление на базовата цена.
* Работи с файлове за съхранение на билетите и картите.
* Извежда статус в конзолата и записва билета в `.txt` файл.

---

### Заключение

`TicketManager` обединява логиката по продажба на билети, като абстрахира конкретните типове потребители. Разделянето на функции със и без намаления улеснява използването от `AdminUser`, `UnsignedUser` и други.
